# Dodge Battle 🎮

An action-packed 2D arcade dodging game built with Python and Pygame. Test your reflexes, dodge incoming obstacles, and survive as long as possible to beat your high score!

## ✨ Features
- Smooth player movement and responsive controls
- Fast-paced obstacle spawning and increasing difficulty
- Real-time score tracking and collision detection
- Clean game-over and restart loop

## 🛠️ Built With
- **Python 3**
- **Pygame**

## 🚀 Getting Started

### Prerequisites
Make sure you have Python installed on your system. You can download it from [python.org](https://python.org).

### Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Dodge-Battle
   ```

2. **Create and activate a virtual environment (optional):**
   ```bash
   python -m venv .venv
   # On Windows:
   .venv\Scripts\activate
   # On macOS/Linux:
   source .venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the game:**
   ```bash
   python main.py
   ```

## 🎮 Controls
- **Arrow Keys / WASD:** Move the player
- **R / Space:** Restart after Game Over *(update this if your key differs)*
- **Esc / Close Window:** Quit the game
