# Dodge Battle

A small 2D Pygame survival game. Move the blue player and dodge the falling red blocks. Your score increases for every block you avoid.

## Run

On Windows, from this folder:

```powershell
.\.venv\Scripts\Activate.ps1
python main.py
```

Move with **WASD** or the **arrow keys**. Press **Space** to restart after a collision, and **Esc** to quit.

The project-local virtual environment is `.venv`.
